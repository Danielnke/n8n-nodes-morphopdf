# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-30

### Added
- Initial release
- PDF Operations: merge, split, compress, rotate, watermark, protect, unlock
- Conversion Operations: PDF to Word/Excel/PowerPoint/Image, Word/Excel/PowerPoint/Image/HTML/Markdown to PDF
- Support for binary data and URL input methods
- Bearer token authentication with API key
- Comprehensive error handling
